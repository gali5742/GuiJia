龟甲 · 六爻 Semantic Router PoC v0.7.1

冻结 v0.6 模型结构：BGE-small-zh-v1.5 q8 → Multinomial Route classifier → route-conditioned Logistic Acceptance Gate。22-route 类别与 v0.7 相同；本修正版只纠正 expansion contrastive hard-negative 的 expected route 语义。

当前实验边界

本页只测试 Semantic Router 组件，不代表整个六爻语义系统。Validation 同时承担每 route acceptance threshold 校准，因此本页指标只能用于开发诊断，不能作为独立 Blind 泛化成绩。v0.7 首轮把“对 A route 是 hard negative、但本身属于 B route”的对照句错误计成 __other__；v0.7.1 修正这一数据语义，不修改模型结构、epoch、learning rate、Gate 算法，也不修改任何 frozen / sealed 数据。

旧 expansion 文本保持不变。只有完整且属于已支持 route 的 contrastive 样本获得 expectedRoute；真正越界、完成态背景或未形成完整占问的样本仍保持 __other__ / underspecified。
