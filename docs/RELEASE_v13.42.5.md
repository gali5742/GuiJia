# 龟甲 v13.42.5 发布说明

v13.42.5 收紧六爻自动取用的置信层级，不修改八字或六爻排盘算法。

## 本版变化

- 高置信自然语言匹配只确认六亲类别。
- 若本卦该六亲仅有一个候选，则该爻作为主要观察对象。
- 若同类六亲有多个候选，当前候选仅作为展示起点，并在界面与复制上下文中明确说明；同类分布仍完整进入分析。
- 普通语言“观察重点”在多候选时采用同样的展示起点语义。
- 典型回归样本：`怀的是儿子还是女儿` 可高置信识别为子孙；当本卦有两个子孙明爻时，不再把其中一爻描述成高置信唯一用神。

## 发布检查

执行：

```bash
npm run predeploy
```

并确认 GitHub Pages 构建、静态资源和 vendor 校验均通过。
