# 龟甲 v13.42.10 发布说明

v13.42.10 在不改动六爻排盘与结构分析核心的前提下，补充出行类观察入口并调整六爻结果录入区的宽屏纵向分布。

## 六爻观察重点

- 新增“出行、旅行与行程”。
- 普通选择以世爻为主要观察对象，同时提示参考应爻与行程结构。
- 自动取用只对“出行、出门、远行、旅行、旅游、出差、行程、旅途”等较明确表达进入高置信出行方向；模糊“出去玩是否开心”仍不因场景词被强行归类。
- 自动建议使用独立 `focusId: travel`，不会与“自己当前的状态”因共同落世爻而高亮错位。
- 复制分析上下文同步记录出行观察口径。

## 六爻结果录入 UI

- 宽屏下结果录入卡改为纵向 flex 容器。
- 六条爻录入行等分卡片剩余高度，使上下分布更均匀。
- 900px 以下仍保持原有自然高度与响应式布局。

## 验证

- 主回归、Lunar 集成、观察重点 4096 卦压力测试、静态站点检查与 Pages 构建均应通过。
