# v13.39.0 八字详细分析页审计

## 目标

总览继续回答“这张盘最值得看什么”；详细页回答“这些判断依赖哪些细部事实，还有哪些结构没有在总览展开”。本版本不扩展总览判断数量，也不加入新的吉凶、格局、喜忌或事件断语。

## 信息架构

### 日主强弱证据拆解

分开陈列：
- 月令季节状态
- 本干通根
- 同类得地
- 天干扶助
- 藏干扶助
- 天干泄耗克
- 藏干泄耗克

数量只作为出现位置记录，不转化为百分比或自动强弱结论。

### 十神透藏分布

按五组十神汇总：比劫、印星、食伤、财星、官杀，并区分天干明透与地支藏干。折叠层可继续查看十神逐项落点。

### 月令主线与显隐核对

展开月支本气、中气、余气，并核对月令本气是否透干、在原局其他地支是否再见。此处只提供格局讨论所需证据，不直接判断成格、破格或用神。

### 干支关系网络

分别展示天干与地支关系，并额外区分：
- 完整三合 / 三会 / 完整三刑
- 半合 / 同方未成局
- 同一柱位参与两项以上关系的共同节点

### 古籍条件对照

不重复总览的完整古籍浏览，只选取当前 matcher 已命中的主要条目，展示原文/条目定位与 `contextMatch` 条件核对结果。

## 代码边界

新增 `js/bazi-detail.js`。该模块只消费 `result` 中已经存在的四柱、月令、藏干、内部关系与古籍匹配结果，不重新计算排盘事实。

`app.js` 只增加 `detail` 视图状态与 `baziDetail` computed；CSS 不变。
