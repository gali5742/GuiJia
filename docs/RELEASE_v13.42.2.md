# 龟甲 v13.42.2 发布说明

v13.42.2 在 v13.42.1 发布候选上收紧六爻自然语言取用建议。核心排盘、用神关系链、应期、飞伏、三合与八字算法均未修改。

## 六爻占问自动取用

- 不再采用“正则列表中第一个命中词直接决定用神”的方式。
- 只维护少量高确定性规则：父母/文书学业、子女子息、钱款收入、任职诉讼疾病、同辈竞争、明确外部对象。
- 每条规则区分强对象词和辅助词；没有强对象词时不会仅靠“顺利、开心、关系、工作”等宽泛表达自动定类。
- 多个方向同时达到推荐门槛且分差不足时返回模糊状态，不抢先选其中一个。
- 未填写、未命中、模糊问题统一显示“取用参考：暂未自动判断”；内部仍以世爻作为初始展示对象，用户可手动确认。
- 只有高置信方向且盘中存在候选时才显示“采用建议”。

## 固定反例

以下问法应保持未自动判断：

- 我今天出去玩能不能玩得开心
- 这件事情能不能顺利
- 我最近状态怎么样
- 和某人的关系接下来会怎样

这类问法可以有不同取用角度，程序不以继续扩充同义词词典的方式强行覆盖。

## 验证

- 完整 JavaScript 回归与 Lunar 集成测试。
- 高置信典型问法、模糊问法、多方向冲突、明确焦点压过次要身份词的专项测试。
- `npm run predeploy`、静态资源与本地 vendor 校验继续作为正式推送门槛。
