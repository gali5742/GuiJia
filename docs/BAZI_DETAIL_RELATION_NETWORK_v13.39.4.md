# v13.39.4 八字详细分析关系网络第二轮调整

## 本轮目标

上一版已经把原始干支关系合并为“关系主线”，但主视图仍然是纵向卡片，本质上仍有罗列感。本轮不再继续润色卡片标题，而是把主视图改成真正的节点—连线网络。

## 呈现方式

- 天干关系与地支关系分别形成网络，只在实际检测到关系时显示。
- 年、月、日、时对应的干或支作为节点；同一对节点之间的多重关系合并到一条边上。
- 合、三合、三会等偏向联结的关系使用柔和绿色；冲、刑、害、破使用柔和红色；同一对节点若同时包含不同性质关系，则使用中性色。
- 三节点以上的关系不再拆成“某两柱关系重叠”“某支连接两端”等多张卡片，而是在一张图中直接显示整体结构。
- 完整三合、三会、三刑或自刑等不适合简单二元连线的关系，作为网络附注保留。
- “查看全部干支关系”继续保留原始条目，作为核对层，不承担主阅读。

## 当前示例

丙午 / 丙申 / 乙卯 / 癸未中，地支主视图会直接形成午—卯—未三节点网络：

- 午—卯：六破
- 午—未：六合 · 同方火
- 卯—未：旺墓半合木

读者首先看到三支彼此交叠，而不是先读两张关系摘要卡。
