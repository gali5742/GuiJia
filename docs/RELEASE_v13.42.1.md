# 龟甲 v13.42.1 发布说明

## 发布定位

v13.42.1 是 v13.42.0 六爻主体分析定型后的发布前收尾版。本版不改变八字与六爻核心排盘口径，重点统一自然语言计数、改善六爻占问填写与取用提示，并完成代码与压力测试复核。

## 用户文案

- 八字、六爻说明性文字中，一至十的数量统一使用汉字；日期、时间、虚岁、卦序、爻位、版本号等结构化数字不改。
- 六爻“所占之事”输入框下新增填写提示：写清“谁／什么事／想问什么结果”即可，不要求使用六亲、用神等术语。
- 取用关键词补充面试 / 录用 / 入职、款项 / 到账 / 回款等高频表达。
- 空白占问与未命中占问分别给出明确提示；用户始终可以跳过自动建议，直接选择实际观察对象。

## 代码清理

- 将一至十自然语言计数统一收束到 `GuiJia.common.formatNaturalCount`，八字详细分析、八字结构解读、原局关系、六爻用神分布与飞伏文献说明共用同一格式器。
- 删除 `bazi-detail.js` 内重复的局部计数映射与格式函数。
- 六爻取用关键词规则与空白 / 未命中提示提升为模块级常量，避免调用时重复构造。
- 清理 `app.js` 中过时的版本号注释；当前运行资源统一使用 `v=13.42.1` 缓存参数。
- 保留应期旧数据结构兼容入口，因为复制上下文与历史候选测试仍显式覆盖该路径；未将仍有测试用途的兼容代码误删为死代码。

## 压力与发布验证

本版额外完成：

- 八字随机四柱 50,000 组：205,149 条结构判断、50,000 份详细分析，检查异常 token 与一至十阿拉伯数量词，0 异常。
- 六爻压力：50,176 组卦象、315,648 个可选用神解释、6,732 组应期与复制上下文、49,152 次古籍 matcher、20,736 组日月状态矩阵，0 异常。
- 六爻压力继续覆盖暗动、日破、旬空、月破、回头生克、进退、墓绝长生、化空、完整 / 待补三合以及两种晚子时换日口径。
- `npm test`、Lunar 集成、全部 JavaScript `node --check`、静态站点校验、Pages artifact vendor 校验与 `npm run predeploy` 均通过。

正式推送前仍建议按 `docs/DEPLOYMENT_CHECKLIST.md` 做一次浏览器人工 smoke test。
