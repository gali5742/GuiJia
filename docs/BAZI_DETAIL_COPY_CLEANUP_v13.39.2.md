# v13.39.2 八字详细分析用户向文案清理审计

## 目标

本轮不调整八字详细分析页的结构，只检查用户可见文案，进一步区分：

- 当前命盘的事实与局部归纳；
- 页面实现说明、阅读顺序提示、统计面板式信息。

原则是：**详细页尽量只说这张盘有什么、这些结构怎样相互关联；不再告诉用户页面怎样工作，也不反复说明应该按什么顺序阅读。**

## 清理内容

### 1. 删除页面实现说明

删除：

- “三页共用同一命盘数据，切换不会重新排盘。”

这属于页面状态实现，不影响用户理解命局本身。

### 2. 删除重复阅读指令

删除：

- “先看月令与根气，再看……”
- “先看十神是否明透，再看……”

日主强弱与十神模块已经有局部归纳和下方证据，不再额外插入教学式阅读顺序。

### 3. 归纳只描述当前盘面

调整：

- 强弱归纳只保留季节、通根、同类得地、扶助、泄耗克等实际事实；
- 十神归纳只保留哪些十神透出、哪些只见于藏支；
- 月令归纳只保留本气、十神、本气是否透出及是否在其他地支再见；
- 干支关系归纳只保留实际关系与共同节点，不附加“宜如何观察”等阅读方法。

### 4. 去掉统计面板式提示

干支关系模块不再在右上角显示：

- “天干 N 项”
- “地支 N 项”

共同节点折叠中也由“同时牵涉 N 项关系”改为“同时关联”，把注意力放在关系本身而非数量。

### 5. 古籍说明收束

古籍条件对照保留必要边界，但模块说明改为：

> 原文或条目定位与本局相关条件并列呈现；条目对应本身不等于古籍结论已经成立。

不再强调页面操作或“逐项查看”的过程。
