# 龟甲 v13.42.11 发布说明

v13.42.11 在不修改六爻排盘与结构分析核心的前提下，新增“失物与寻找”观察重点，并收束当前版本尚未上线的专项分类文字。

## 失物与寻找

- 新增独立观察重点 `lost-item`，主要观察类别为妻财。
- 自动识别只对明确的失物、物品遗失或寻找物品表达给出高置信建议。
- 与“钱财、收入与交易”共享妻财目标，但使用不同 `focusId`，避免 UI 高亮错位。
- 复制分析上下文保留“失物与寻找”专项观察方向。

## 当前分类边界

- 从父母类现有提示与自动相关词中移除尚未单独设计的家宅/住宅表述。
- 从子孙类自动相关词中移除尚未单独设计的医药/治疗表述。
- 行人/寻人专项尚未上线，当前版本不提前展示相关入口或提示。

## 验证

- 自动取用、观察重点映射、复制上下文、4096 卦全观察重点压力测试、主回归、Lunar 集成与 Pages 预部署检查均需通过。
