# 龟甲 v13.42.15

## 本次修订

### 1. 当前日月补三合

六爻两动爻已具三合两支时，若所缺一支正是当前日辰或月建，则直接列为当前成局。当前环境已经补足后，不再生成下一次同支日的“三合补局”应期。

### 2. 占问目标时点

占问中的相对日期与明确公历日期进入独立目标时点：

- 今天 / 今日
- 明天 / 明日
- 后天
- 本周末 / 下周末 / 周末
- YYYY年M月D日、YYYY-M-D、M月D日、M/D

目标时点显示目标日期与日柱，并列出与主要观察爻、盘中直接合冲/值日关系、月建和当前日辰的直接关系。

### 3. 日辰状态冲突去重

日辰与爻支直接相冲时，优先保留日冲、日破或暗动结构，不再同时追加同五行“日辰比扶”。月破同理不再与同五行月令比扶并列。六合仍可与五行生扶关系同时保留。

### 4. 出行观察对象语义

出行类占问以世爻作为主要观察爻，并参考应爻与行程结构。详细页、结构解读和复制上下文不再把“世爻恰临某六亲”写成“出行以该六亲为用神”；生扶、克制与间接制约关系改为围绕主观察爻表述。

### 5. 未变更范围

- 八字排盘及分析不变。
- 六爻基础排盘、纳甲、世应、六神、动变算法不变。
- Vue 3.5.40 与 lunar-javascript 1.7.7 不升级。
