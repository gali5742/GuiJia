# 龟甲 v13.42.16

## 本次修订

### 1. 三合“支齐”与“成局”分离

三合结构在三支齐备后继续检查参与支状态。若参与支旬空、月破，或参与的变爻处于化墓条件，不直接列为成局，而列为“三合待实”。

例如申、子两动而当前辰日补足申子辰时：若子水旬空，则显示“三支已补齐，但子水旬空，三合局尚未落实”，不再写成已经成局。

### 2. 明确目标时间限制应期范围

“今天 / 明天 / 后天 / 周末 / 指定日期”等占问已有明确目标窗口时，普通应期只保留目标窗口内的触发。目标窗口外的未来逢冲、逢值等不再与本次问题并列。

### 3. 出行观察对象术语统一

出行继续以世爻作为主要观察爻，并统一使用：

- 生扶五行
- 克制五行
- 间接制约五行

结构解读不再混用元神、忌神、仇神名称。

### 4. 古籍匹配同步观察语义

出行类以世爻为主要观察对象时，不再自动加入《增删卜易》“用神章”作为该爻的直接匹配依据；与当前结构直接相关的世应、动变、空破、三合及八宫条目仍正常匹配。

### 5. 上下文收尾

没有目标窗口内应期时，复制分析上下文省略“应期观察”空标题。

### 6. 未变更范围

- 八字排盘及分析不变。
- 六爻基础排盘、纳甲、世应、六神不变。
- Vue 3.5.40 与 lunar-javascript 1.7.7 不升级。
