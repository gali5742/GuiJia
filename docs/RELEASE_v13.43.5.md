# 龟甲 v13.43.5 · 六爻关键静爻统一时间状态

## 目的

补齐 v13.43.4 时间范围分析中对关键静爻状态变化的漏检，使旬空 / 月破等时间状态不再只对动爻生效。

## 变更

- 新增 `rangeStaticValueMeta` 与静态 `KeyLine` 判定。
- 世应对应爻、旬空静爻、月破静爻进入统一时间状态观察。
- 旬空静爻复用冲空 / 填实 / 出空 / 出空后逢值状态机。
- 月破且与主要观察爻有明确生克角色的静爻，逢值进入“月破复核”。
- 静卦将关键静爻状态提升为一级节点；动卦中的非世应静爻保持次级，避免范围节点数量失控。
- 普通无特殊状态静爻不因值日自动提升。

## 固定回归

- 无妄静卦：8/18 子日识别旬空应爻出空并逢值；8/20 寅日识别生扶静爻月破逢值复核。
- v13.43.4 丰之大有向量继续通过，确保新增静爻状态不会挤掉既有高优先关键节点。

```powershell
npm run predeploy
git diff --check
```
