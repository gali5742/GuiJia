# 龟甲 v13.44.0-beta.2 · Beta 手测修复与观察爻之变专项

本轮严格限定为 beta.1 手测暴露的三个用户输出问题修复，并对“主要观察爻自身之变逢值是否被过程节点系统性遗漏”只做专项统计，不修改其筛选规则。

## 修复项压力结果

- 连续范围运行：4096
- 一周日期选择运行：4096
- 摘要实质效力缺少用户可见证据：0
- 时间输出重复句号：0
- 同条件并列：122
- 真实权衡并列：2396
- 并列类型与文案不一致：0

## 只观察、不修改：主要观察爻自身之变逢值

- 主要观察爻发动：2048
- 其变爻支落在 8/15～8/20 范围：992
- 该日期已进入过程关键节点：392
- 该日期未进入过程关键节点：600
- 遗漏比例：60.48%

当前过程筛选仍以 legacy primary tier 为入选门槛；`TARGET_CHANGED_VALUE` 属于 secondary，而 Structural Relevance 已把 `main-observer-change` 定为高相关层。因此该统计反映的是重构后“相关性层已升级、过程节点入口仍沿用旧 tier”的架构边界。beta.2 按批准范围只记录，不改规则。

## 结论

- beta.2 三个已批准修复项的压力阻断项为 0。
- 观察爻之变逢值专项确认属于广泛现象，需在 RC 前作为单独的“过程节点入口是否迁移到新相关性模型”决策处理；不应以零散事件补丁解决。
