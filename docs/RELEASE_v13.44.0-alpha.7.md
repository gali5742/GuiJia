# 龟甲 v13.44.0-alpha.7 · Date Selection 第 7 步

## 目标

把日期选择从 Candidate Output 中拆出，明确“哪天更适合”的比较原则，避免再次回到 supportive/adverse 总分式补偿。

## 原则

1. **受制为硬负担**：有未受制日期时，受制日期不能仅因同时存在生扶/比和而直接压过未受制日期。
2. **同层非补偿比较**：同一受制层级内，只比较是否有明确助力、是否有软负担，不把六维换算为总分。
3. **不规定生扶 > 比和**：两者都作为助力，但具体性质保留在 Evidence 中。
4. **不规定泄力 > 耗力或相反**：两者都作为软负担。
5. **互有长短则并列**：使用 Pareto 非支配前沿，不为了给出唯一答案而隐藏加权。

## 结果

- 4096 卦一周日期选择：0 个硬受制门槛违规；0 个第一前沿被同层候选支配。
- 4096 卦离散两日比较：0 个硬受制门槛违规；0 个支配错误。
- 一周选择最大第一前沿为 5 天，说明在只使用六维效力时确实存在大量不可比日期；这是下一阶段需要决定“是否引入结构相关性层”的依据，不在本阶段用隐藏分数修饰。

## 用户接口

无变化。正式页面、复制分析上下文仍使用 legacy 时间输出。
