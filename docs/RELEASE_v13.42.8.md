# 龟甲 v13.42.8 发布说明

v13.42.8 统一六爻自动取用中“具体外部合作对象”的规则边界。本版不修改排盘、纳甲、世应、日月、动变、飞伏或应期算法。

## 修改

- “合作伙伴、合作方、合伙人、客户、甲方、乙方”等明确指向具体外部主体的表达，高置信映射到应爻。
- “合伙人”从兄弟自动关键词中移除，避免同一句同时触发“兄弟”和“应”两条方向。
- “同辈、朋友与竞争”的说明不再包含合伙；“对方／外部对象”说明同步覆盖合作伙伴与合伙人。
- 只有宽泛的“合作”而没有明确外部对象时，不自动高置信取应，继续进入人工观察重点确认。

## 回归重点

- “合作伙伴是不是真心靠谱” → 应。
- “我的合伙人靠不靠谱” → 应，且由 counterparty 规则命中。
- “竞争对手最近会怎么做” → 兄弟。
- “这次合作能不能顺利” → 不高置信自动取用。

正式发布前执行 `npm run predeploy` 与 `git diff --check`。
