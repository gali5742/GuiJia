# 龟甲 v13.43.1 · 六爻时间范围分析

## 范围

本版本不修改八字排盘、六爻纳甲、八宫、世应、六神与 vendor 依赖，只扩展占问时间进入六爻分析后的消费层。

## 主要变化

1. `QuestionTimeScope` 的连续范围进入 `buildQuestionTimeFocus()`，生成独立 `kind: range` 结果。
2. 范围内逐日计算目标日干支与关键结构，只选取高区分度节点展示。
3. 范围问句分为 `event-occurrence`、`process-evaluation`、`date-selection`、`deadline` 四种模式。
4. 旬空填实 / 冲空、月破逢值 / 合破、主要观察爻逢值 / 合 / 冲、变爻、世应、关键动爻、三合待补 / 待实等可进入范围节点。
5. 范围分析存在时，不再重复渲染独立“应期观察”。
6. 单日目标时点修复重复标签，并把普通五行作用改为面向观察对象的状态表达。

## 回归重点

- 明天出行如何：仍为单日“目标时点”，且不重复拼接爻位。
- 本周能收到消息吗：显示本周范围和事件触发节点。
- 8月15日至20日出差如何：显示六天范围和过程关键节点。
- 这周哪天适合签合同：进入日期比较模式。
- 月底前能收到钱吗：进入期限内触发观察。
- 近期会不会有消息：保持模糊时间，不创建硬范围。
