# 八字结果页全体审视 v13.40.7

## 审视范围

本轮覆盖八字结果的三个页面：原局总览、详细分析、岁运分析，并检查它们之间的信息分工、重复项、遗漏项与用户可见文案。六爻页面不在本轮改造范围内，仅做回归确认。

## 当前三页职责

### 原局总览

- 原局四柱：四柱、十神、藏干、十二长生、纳音、旬空。
- 结构解读：只保留综合判断，不再展开同一批依据。
- 月令与强弱线索：只呈现月令状态、根气、扶助、泄耗克四类速览。
- 原局关系概览：按天干、地支分别概括关系；不再重复全量关系标签。
- 古籍、神煞、宫位、胎元命宫身宫：作为参考或辅助信息。
- 当前岁运入口：只负责跳转到独立岁运页。

### 详细分析

- 日主强弱证据拆解：给出根气与扶泄的具体落点。
- 十神透藏分布：结构概括 + 十神具体落点。
- 月令主线与显隐：展开月支藏干、本气显隐与十神主线。
- 原局关系网络：简单关系用图，复杂关系用矩阵；完整三合、三会、三刑提升为一级结构。
- 古籍条件对照：逐项核对原文/条目与当前命局条件。
- 复制分析上下文：保留完整结构与后台使用边界，供后续综合分析。

### 岁运分析

- 大运：长期背景、结构变化与关系落点。
- 流年：年度主题、岁运衔接、核心触发与新增作用。
- 流月：节令背景、层间衔接、结构变化与原局作用。
- 十二流月：按节令交接浏览。

## 本轮发现并修正的重复

1. 原局总览“结构解读”的“查看依据”与详细分析重复，已移除。解释引擎的 evidence 数据仍保留，供复制上下文使用。
2. 原局总览“月令与结构证据”中的“方局”与关系模块重复，已从强弱速览删除；方局统一由关系概览/关系网络承担。
3. 原局总览原先用彩色标签列出关键关系，并可再次展开全量关系，与详细页关系网络重复。现改为按天干、地支分组的自然语言概括，并提供“查看关系网络”入口。
4. 原局总览原有多处“使用边界”“不直接判断”等前台说明，与近期岁运页的语言原则不一致，已从主要结果模块中清理。
5. baziKeyRelations 只服务旧的三条关键关系标签，UI 移除后已同步删除无用计算。

## 本轮发现并修正的遗漏/不一致

1. 时间页实际包含大运、流年、流月，但页面名称长期只写“流年流月”。现子导航统一为“岁运分析”，页面标题与工具栏明确写“大运流年流月”。
2. 原局关系概览的主文字此前沿用合冲关系标签的红绿字体，与相邻正文不一致。现主概览使用统一正文色；关系色只保留在详细网络/矩阵中作为视觉编码。
3. “当前岁运”入口原文带有“已移到独立页面、不再被挤压”等改版说明，现改为直接说明可查看的内容。
4. 宫位、神煞、胎元命宫身宫的总览说明中，清理了不必要的后台边界式措辞，保留其实际参考方向与体系差异。

## 有意保留的层级重叠

以下内容在不同页面都出现，但职责不同，因此不视为重复：

- 月令状态：总览给速览；详细页给根气、扶助、泄耗克的具体位置。
- 原局关系：总览给概括；详细页给网络/矩阵及完整清单。
- 古籍：总览负责书目入口；详细页负责条件核对。
- 结构解读与分项模块：结构解读负责把多个因素合成命题；分项模块负责分别呈现月令、十神、关系等结构。

## 当前未发现的主要内容缺口

原局四柱、月令/强弱、十神透藏、月令主线、干支关系、古籍、辅助神煞与三垣、大运、流年、流月均已有明确归属，暂未发现需要新增一个独立分析模块的内容缺口。

## 后续可选项（非本轮阻塞项）

- 目前“复制分析上下文”只针对原局详细分析。若后续需要把选中的大运、流年、流月交给外部分析，可再增加“复制岁运上下文”，但不应与原局上下文混为一个按钮。
- 古籍条件对照仍保留必要的适用范围说明；这类文字属于来源核对信息，不与结果页的后台控制边界混同。
