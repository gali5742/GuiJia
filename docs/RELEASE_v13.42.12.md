# 龟甲 v13.42.12 发布说明

v13.42.12 不修改六爻排盘、纳甲、世应、日月、动变、飞伏、三合或应期算法，集中收束“占问文字 → 观察重点/取用类别”的有限自然语言规则。

## 本次修改

- 将 36 条真实典型占问加入固定回归集：事业财运 8 条、感情婚恋 8 条、考试学业 6 条、出行安全 5 条、失物寻人 2 条、怀孕子女 3 条、官司纠纷 4 条。
- 补齐高特异常见表达：`跳槽`、`回本`、`奖金`、`正缘`、`考研`、`论文`、`志愿`、`留学`、`航班`、`小孩`、`仲裁`、`男孩还是女孩 / 男宝女宝 / 胎儿性别`。
- `加薪` 仅作为财务相关弱信号；“升职加薪”仍由更明确的“升职”稳定落官鬼，不制造官鬼/妻财假冲突。
- 修复同一高分区间但最终 target 相同仍被判 ambiguous 的问题；同 target 时允许继续高置信，并用规则优先级保留更具体的观察重点，例如“对方是不是真心想结婚”优先 `relationship` 而非 `counterparty`。
- 失物增加有限句式识别，不枚举手机、钱包、钥匙等物品名；“X 丢在哪里 / 找不到且询问能否找回”等物品遗失句式可进入 `lost-item`，人物/宠物“走丢 / 失踪”排除。
- 出行规则新增天气焦点抑制；包含天气、下雨、晴天、气温等明确天气问题时，不因“旅游/目的地”自动落出行。
- 保留高置信边界：情感态度、冷战联系、泛化关系挽回、车辆故障、天气问题等仍允许返回“暂未自动判断”。

## 固定回归集结果

本版 36 条固定问法中：

- 30 条高置信命中；
- 6 条保持未自动判断；
- 0 条误报为冲突。

其中“面试能排第几名”在缺少升学/求职上下文时仍按当前高置信 `面试 → 官鬼` 规则处理；若实际是升学面试，用户可通过“观察重点”切换到学业/文书方向。
