# 龟甲 v13.42.7 发布说明

v13.42.7 收口六爻自动取用在“一个类别对应多个具体爻”时的前台语义，并统一手动具体爻选择的折叠 UI。本版不修改排盘核心与应期算法。

## 本版变化

- 多候选且尚未由用户确认具体爻时，详细页由“当前用神”改为“当前观察对象”，并明确“展示位置”和“同类候选”。
- 结构解读在该状态下使用“观察对象状态 / 观察对象关系链”语义；复制上下文仍明确记录取用类别由占问文字高置信识别，具体爻仅为展示起点。
- 古籍匹配的取用依据在多候选时改为“当前取用类别 + 同类候选 + 展示起点”，不再写成具体爻已经被确认。
- 同类候选仅承诺完整保留在盘面中；尚未实现多候选并行断卦时，不再用“分析中一并保留”造成误解。
- 自动取用理由改为引用本次实际命中的高置信词；例如“今年能不能升职”说明“升职”命中官鬼，不再顺带列出诉讼、疾病。
- 手动具体爻选择改为标准 `fold-card` 折叠项目，与飞伏、《周易》和其他折叠模块保持一致。

## 验证

- Lunar 集成：9 / 9。
- 新增多候选观察语义、命中理由与手动折叠 UI 回归。
- `npm run predeploy`、Pages 构建、vendor 校验与静态资源校验均通过。
