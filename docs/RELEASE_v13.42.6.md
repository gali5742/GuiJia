# 龟甲 v13.42.6 发布说明

v13.42.6 专门完善“伏神成为主要观察对象”时的展示、解释与应期语义，不修改六爻排盘、纳甲、八宫、世应、日辰换日或占问时间范围识别。

## 本版变化

- 伏神主观察对象使用独立形态：显示“伏神”，不再输出“本爻静”“静爻逢冲”等明爻语义。
- 日月关系摘要允许同时呈现地支冲合与五行生克，避免“日合”覆盖“日生”等已存在结构。
- 用神关系链优先说明飞神与伏神的实际生克、六合／六冲关系；已进入飞伏主线的飞神不会再作为普通元忌仇重复罗列。
- 应期对伏神单独分流：保留伏神自身旬空、月破、日月见合等触发，并增加“伏神值日”“冲飞”观察点；不再套用普通静爻的“静爻逢冲”。
- 复制分析上下文同步上述语义。
- “今年／本月”等占问时间范围识别本版不处理，现有应期搜索窗口保持原逻辑。
