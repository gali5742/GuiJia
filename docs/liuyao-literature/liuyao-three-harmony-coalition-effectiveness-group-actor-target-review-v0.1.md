# 1. Executive Decision

本轮最重要的结论是：

```text
valid + manifest Three-Harmony Coalition
```

可以在传统判断中成为：

```text
group-level actor
```

但绝不能进一步偷换成：

```text
omnidirectional actor
```

即：

```text
三合成局
≠
自动获得对全卦任意 line / role / target 的生克边
```

传统材料明确支持的，是经过题义 / 角色确定后的定向结构，例如：

```text
coalition → 世
coalition → 应
inner coalition → outer coalition
outer coalition → inner coalition
```

并且传统材料同时证明：

```text
base five-element relation
≠ realized effect
```

因为至少还需要：

```text
1. Coalition Condition / Vigor
2. Direction / Role Adjudication
3. Target Condition / Resistance
4. Path / Third-Party Intervention
5. Topic-specific meaning
```

因此本轮将 shared research responsibility 收束为：

```text
Coalition Identity
↓
Manifestation Gate
↓
Role-Resolved Directed Relation
↓
Coalition Condition / Vigor
+
Target Condition / Resistance
+
Path Modifiers
↓
Group-Actor Effectiveness
↓
Domain Evidence
```

不是：

```text
三合火局
+
目标金
→ 火克金
→ adverse
```

最终总体分类：

```text
group_actor_structure = strongly_supported
omnidirectional_group_graph = rejected
role_resolved_direction = required
coalition_condition = required_dimension
target_condition = required_dimension
group_vs_group_relative_force = traditionally_evidenced
constituent_global_deletion = not_supported
role_sensitive_directionality = partially_solved / modern_conflicted
universal_group_effectiveness_formula = not_ready
Formal Expansion = not_authorized
```

本轮输入前提是：

```text
formation identity exists
```


这样可以防止把：

```text

```


# 3. Classical Direct A：《增删卜易》明确存在 Coalition → 世 / 应

《增删卜易》三合章直接给出：

```text
世爻在局为美
若世不在局
→ 局生世为吉
→ 局克世为凶
```

并进一步按具体题目区分：

```text
占功名：三合官局生世 → 利我
         三合官局生应 → 利他

占财：财局生世 → 利我
      财局生应 → 利他
```

来源：

```text
SRC-ZSBY
independenceGroup = TRAD-ZSBY
location = 三合 / 六合相关章
```

这组原文直接证明：

```text
coalition-level element relation
```

可以被传统用于：

```text
directed role relation
```

即 coalition 不是只表示：

```text
三个成员属于同一组
```

而确实可以作为整体与角色对象发生：

```text
生 / 克
```

关系。

但这里必须注意：

```text
世
应
```

不是任意 target。

原文在题义中已经给了：

```text
我 / 他
```

这一 role resolution。

所以安全抽取是：

```text
role-resolved group relation exists
```

而不是：

```text
coalition may act on every line in the hexagram
```

分类：

```text
classical_direct_group_to_role_relation
```

# 4. Classical Direct B：特定主题规则反复使用“局 → 世”的整体方向

《增删卜易》升迁相关章节进一步明确：

```text
三合官局而生世者
→ 必得

三合局而生应爻
→ 不得
```

这里仍然不是简单的：

```text
官局旺 = 得官
```

而是：

```text
官局
+
向谁发生关系
```

决定该主题的意义。

同一传统体系内已经可以看到：

```text
coalition identity
≠
coalition direction
```

也就是说：

```text
官局
```

只是 actor 的属性；

```text
官局生世 / 官局生应
```

才是进入题义判断的定向关系。

这与 Directed Interaction Effectiveness 的方向性原则完全相容。

# 5. Classical Direct C：Coalition Membership 与 External Directed Relation 不是一回事

《增删卜易》同一段又说：

```text
占出行
→ 用神在三合内，被合而留

占行人
→ 用神在三合内，被合不回
```

这证明：

```text
target ∈ coalition
```

本身可以形成一种传统意义。

它不是：

```text
coalition generates target
```

也不是：

```text
coalition controls target
```

而是：

```text
membership / enclosure / binding-like relation
```

因此未来研究层必须区分：

```text
A. coalition external relation
   coalition → target

B. coalition membership relation
   target ∈ coalition
```

不能把：

```text
target is one constituent
```

强制转成：

```text
coalition → target same-element support
```

这一区分非常重要，因为后续 Travel / Person Return 等主题可能给 membership 赋予：

```text
留 / 不回
```

而其他主题并不一定如此。

分类：

```text
membership_relation = traditionally_evidenced
membership_meaning = domain_specific
```

# 6. Classical Direct D：Group-vs-Group 是真实存在的传统结构

《增删卜易》两村争水案例提供了目前最强的 group-level interaction witness。

结构：

```text
内卦
→ 亥卯未木局
→ 我村

外卦
→ 巳酉丑金局
→ 他村
```

传统断法直接进入：

```text
金局 → 克 → 木局
```

而不是逐条解释：

```text
巳克谁
酉克谁
丑克谁
```

更关键的是，作者还解释：

```text
今彼此两村
→ 内外两卦人众同心
→ 彼此合局
→ 故舍世应而不用
```

这证明在某些题义中：

```text
coalition role
```

可以临时取代普通：

```text
世 / 应 role proxy
```

成为双方整体 actor。

因此：

```text
Group Node → Group Node
```

不是现代 graph abstraction 发明出来的概念，而是有直接传统案例结构。

但是：

```text
两村争水允许内外局代表双方
```

不能推广成：

```text
所有题目都可让内外局取代世应
```

作者自己明确说：

```text
若无内外合局者
→ 须看世应
```

因此：

```text
role replacement by coalition
= context-specific traditional rule
```

# 7. 最大 Effectiveness 证据：“衰金不克旺木”

两村争水案例不是只说：

```text
金克木
```

而是明确继续判断：

```text
金局来克木局
+
衰金
+
旺木
→ 衰金不克旺木
```

这句话对本项目价值极高。

它直接否定：

```text
coalition A controls coalition B
→ A effectively harms B
```

传统实际结构是：

```text
Topology:
金局 controls 木局

Condition:
金局衰
木局旺

Effectiveness:
control does not realize strongly enough
```

因此 shared group-effectiveness 至少必须拥有：

```text
Actor Condition
+
Target Condition
```

两端。

这与此前 Directed Interaction Effectiveness 的：

```text
Source Actionability
+
Target Condition
```

完全同构。

所以不应另造：

```text
SanHe special strength engine
```

更合理的研究方向是：

```text
Coalition actor
```

接入共享 directed interaction 框架。

分类：

```text
classical_direct_group_relative_force
```

# 8. 同一案例还证明 third-party intervention 可作用于 group actor

两村争水断语还继续使用：

```text
日主制金
```

作为：

```text
金局更不足畏
```

的辅助判断。

这说明传统 network 并不是：

```text
Group A → Group B
```

两节点封闭关系。

还可能存在：

```text
Calendar / Third Party
→ constrain Group A
→ modify Group A → Group B effectiveness
```

因此此前 Directed Interaction Path 研究的：

```text
source_suppressed_by_third_party
```

原则上可以扩展到：

```text
coalition_suppressed_by_third_party
```

作为研究结构。

但本轮不把这一点写成可执行 rule，因为：

1. 日辰对 coalition 的作用通道尚未完整 formalized；
2. coalition constituent 与 coalition-level calendar condition 的边界仍需继续清理；
3. multiple calendar / moving / coalition actor 的 precedence 尚未建立。

当前只确认：

```text
group actor can participate in a larger directed network
```



```text
target condition is an independent effectiveness dimension
```


# 10. “局旺”应归入 Coalition Condition，而不是 Formation

部分《增删卜易》整理本保存：

```text
日建、月建但有一在局中
→ 谓之局旺
```

王虎应《增删卜易评释》与《六爻预测自修宝典》也采用：

```text
合局可以有旺衰
```

并明确强调：

```text
合局的力量大于单支
```

本轮最安全的职责拆分是：

```text
formation
→ coalition 是否成立

manifestation
→ coalition 当前是否可兑现

coalition condition / vigor
→ coalition 当前作用能力的条件

relation
→ coalition 朝谁生 / 克 / 比和

effectiveness
→ 这条 directed relation 是否真正落实
```

所以：

```text
局旺
≠ 成局
≠ manifest
≠ effective
≠ favorable
```

尤其王虎应自己举出的官运案例非常说明问题：

```text
官鬼午火持世
+
得日生
+
三合成官局
→ 可谓之旺

但
官局生应
→ 判难升
```

这说明即使在其现代体系内部：

```text
coalition vigor
```

也不能覆盖：

```text
direction / target role
```

因此未来严禁：

```text
coalitionVigor += 1
→ outcome += 1
```

```text

independenceGroup = MOD-ZCB
verification = scan_verified
```

```text
数动爻中复合构成三合局

再整体以合局形式

指向作用世爻或用神
```

其主管职位案例：

```text
巳酉丑三合子孙金局
↓
整体冲克用神官鬼卯木

用神受冲克而衰败
```

```text
复合动爻以合局形式整体指向世用
```

```text
自占自事
+
```


# 16. Constituent Supersession：可以确认“整体化”，不能确认“全局删除”

一个合法 coalition 形成后，constituent 怎么处理，是未来 graph model 最危险的地方之一。

错误方案 A：

```text
申 → target
子 → target
辰 → target
+
水局 → target
```

这会把同一结构重复计算。

错误方案 B：

```text
一旦成水局
→ 删除申、子、辰所有个人事实和所有边
```

这又会丢失：

```text
旬空
月破
入墓
合绊
变爻来源
角色位置
应期
```

等 constituent-specific 信息。

当前证据支持的是：

```text
constituent facts persist
+
resolved coalition relationship may supersede ordinary constituent-level interaction interpretation
```

朱辰彬明确采用：

```text
复合成局
→ 整体指向世 / 用
```

《增删卜易》两村争水也直接把：

```text
内外两局
```

作为双方整体，甚至在该题义中：

```text
舍世应而不用
```

这些都支持：

```text
group-level adjudication can supersede lower-level role interpretation
```

但没有足够证据支持：

```text
所有 constituent relation globally disabled
```

所以当前分类：

```text
constituent_interaction_supersession
= supported in resolved group relation

global constituent edge deletion
= not supported
```

# 17. Coalition Member 的独立事实必须保留

即使 group actor 成立，成员仍需保留自己的：

```text
position
branch
source = original / changed / calendar / dark-moving
activity provenance
void / break / tomb / bound status
role identity
```

原因：

1. temporal manifestation 仍依赖哪个 constituent 空破墓绊；
2. modern formation rules 仍区分 original / changed / dark moving；
3. role-sensitive direction 可能依赖是否有世 / 应 / 用神在 coalition 内；
4. membership itself can carry domain meaning；
5. future conflict resolution 可能需要知道谁是 group center / source contributor。

因此 group actor 应被研究为：

```text
higher-order actor
```

而不是：

```text
replace-and-delete constituent data
```

# 18. “局旺”不能等价于三条 constituent 旺度相加

传统 / 现代材料虽然使用：

```text
局旺
```

但当前没有证据支持：

```text
局旺 = constituent1 score + constituent2 score + constituent3 score
```

更没有依据支持：

```text
日建在局 +1
月建在局 +1
三爻皆旺 +3
```

两村争水案例中的：

```text
衰金
旺木
```

说明 coalition 可以整体被描述为旺 / 衰。

但如何从 constituent、日月、活动来源、空破墓等综合得到：

```text
coalition condition
```

仍未建立跨文本稳定算法。

所以本轮只确认：


未来可以研究统一，但不能现在假装已经统一。
