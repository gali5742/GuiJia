# v13.39.3 八字详细分析关系网络与上下文入口调整

## 目标

本轮只处理八字详细分析页两个问题：

1. “干支关系网络”不再把天干、地支、半合、同方作为多个并列清单直接铺开，而是先把重复关系与共同作用合成为可阅读的关系主线。
2. “复制分析上下文”从原局总览移到详细分析页，使总览保持摘要定位，完整上下文入口与证据展开集中在同一页。

## 关系网络的新层级

主视图优先按以下顺序合成：

- 同一对柱位同时存在多种关系：合成“XX两柱关系重叠”；
- 同一干支以相同关系反复作用于不同柱位：合成“形成重复六破 / 重复相冲”等；
- 其余仍围绕同一柱位相接的关系：合成“连接两端 / 连接多组关系”；
- 无法继续合成的单一关系才单独呈现。

完整原始关系仍保留在“查看全部干支关系”折叠项内，方便核对，但不再作为主视图。

示例：

- 年支午—时支未同时见六合、同方火：显示为一条“年时两柱关系重叠”；
- 日支卯同时被年支午、时支午六破：显示为“日支卯形成重复六破”；
- 时干壬同时与年、月两丙相冲：显示为“时干壬形成重复相冲”。

## 复制入口

- 原局总览“结构解读”标题区不再显示“复制分析上下文”；
- 八字详细分析页顶部显示该按钮；
- 复制内容本身仍沿用既有完整八字分析上下文格式，没有删减。
