# 龟甲 v13.43.2 · 六爻时间节点效力与日期比较

## 范围

本版本不修改八字、六爻纳甲、八宫、世应、六神与 vendor 依赖，只继续扩展 `QuestionTimeScope` 进入六爻后的判断层。

## 主要变化

1. 范围节点新增 `effect / direction / tier / subject` 结构，区分生扶、受制、触发、牵制与交错。
2. 静爻逢冲不再统一视为普通冲：按目标日所在月建重新核对旺相 / 休囚，区分暗动触发与日破倾向。
3. 静爻逢合显示合起；动爻逢合显示合绊。
4. 其他动爻的值、冲、合会结合其相对主要观察爻的元 / 忌 / 仇五行关系计算方向；出行类前台仍使用生扶 / 克制 / 间接制约的用户语言。
5. 日期比较新增规则层 assessment 与 comparison：候选按直接作用优先于间接结构的规则比较，不暴露数值积分。
6. 过程型范围改为阈值式节点筛选，删除“至少凑两项”的 fallback。
7. 离散候选分别保留原始标签并进入比较。
8. 三合古籍 matcher 分为待补、空破待实、入墓待冲三类。

## 回归重点

- `8月15日至20日出差如何`：普通低区分度日期不再为凑数量进入关键节点。
- `这周哪天适合签合同`：出现比较结果与候选判断。
- `明天还是周五哪个好`：两个候选标签分开，并有相对比较结果。
- 静爻休囚受月克再逢冲：显示日破倾向；静爻逢合：显示合起。
- 三合三支齐备但旬空：古籍参考改匹配“空破待填满”。
