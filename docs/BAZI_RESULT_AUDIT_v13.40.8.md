# 八字结果页全体审视（v13.40.8）

## 审视范围
- 原局总览
- 详细分析
- 岁运分析（大运 / 流年 / 流月）
- 三页之间的导航与信息职责

## 当前职责划分

### 原局总览
负责快速建立全盘印象：四柱、结构解读、月令与强弱线索、原局关系概览、古籍入口、神煞与辅助项，以及进一步分析入口。

### 详细分析
负责展开原局细部：强弱证据、十神具体落点、月令显隐、原局关系网络 / 矩阵、古籍条件核对与复制分析上下文。

### 岁运分析
负责时间层变化：大运作为长期背景，流年作为年度层，流月作为短期层；重点解释延续、补齐、再次参与与新增关系。

## 本轮发现并修正
1. 原局关系概览此前仍带暖色卡片气质，正文与左侧“月令与强弱线索”不一致。现统一为证据型卡片样式。
2. 多项原局关系此前压在一段摘要中。现按天干 / 地支分组，并把每项关系逐条换行。
3. “查看关系网络”与全局三页导航、底部分析入口功能重复，现删除。
4. 原局总览底部此前只提供岁运入口，遗漏“详细分析”的等价入口。现增加两个同级按钮。
5. 八字结果页仍残留“查看流年流月”旧称，现统一为“查看岁运分析”。

## 重复项检查
- 原局总览的关系概览仅作摘要；完整网络 / 矩阵只在详细分析出现，职责不同。
- 总览“月令与强弱线索”不再重复方局；完整方局归入关系模块。
- 总览“结构解读”不再展开详细依据；证据细节归详细分析。
- 岁运分析已移除重复结构证据折叠层，只保留解释后的时间层分析。
- 古籍总览入口与详细页条件核对分别承担“读原文”与“核条件”职责，不视为重复。

## 遗漏项检查
当前未发现阻断使用的分析缺口。三页都能通过顶部子导航互相切换；原局总览底部又增加“详细分析 / 岁运分析”两个显式入口。

可作为后续独立功能考虑、但不属于当前遗漏：为选中的大运—流年—流月生成独立“岁运分析上下文”。
