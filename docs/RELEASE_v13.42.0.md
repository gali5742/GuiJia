# 龟甲 v13.42.0 发布说明

## 发布定位

v13.42.0 是六爻主体分析完成 v13.41.x 连续专项开发后的稳定收束版。八字主体保持 v13.40.16 以来的冻结策略，除明确缺陷外不再改动核心规则。

## 六爻稳定能力

- 京氏八宫、纳甲、六亲、六神、世应与飞伏；
- 月建、日辰、旬空、月破、日冲 / 日合、暗动与日破提示；
- 明动与变爻、回头生克冲合、进退、化空、月破、墓绝长生等状态；
- 用神—元神—忌神—仇神三层来源与直接关系事实；
- 六冲 / 六合、反吟 / 伏吟、按具体爻位来源识别的动变三合；
- 按时间节点聚合的应期观察；
- 24:00 默认换日与 23:00 子初换日两种日辰口径；
- 分点式结构解读、飞伏展示、《周易》经文与结构关联古籍；
- 面向进一步分析的结构化复制上下文。

## 发布前压力验证

此前专项压力覆盖包括：

- 4096 种 6/7/8/9 六爻组合；
- 全部可选用神的关系链与结构解读；
- 静卦、单动、多动、六爻全动；
- 暗动、日破、旬空、月破、回头生克、进退、墓绝长生、化空等交叉结构；
- 完整三合与待补三合的正向 / 反过度识别样本；
- 23:00–00:00 两种换日口径的日辰依赖链与应期时间窗。

正式推送前仍以当前工作区的 `npm run predeploy` 结果为准。
