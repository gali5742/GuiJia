# v13.35.0 古籍浏览统一审计

## 目标

将八字与六爻的古籍引用统一为“总览 + 单书分览”，避免六爻把全部命中文段一次性展开造成页面过长，并减少两套重复 UI 逻辑。

## 实现

1. 在 `js/app.js` 注册共享 `LiteratureBrowser` 组件。
2. 八字、六爻均把 matcher 结果作为 `entries` 传给同一组件。
3. 组件只展示当前实际命中的书目。
4. “总览”按书聚合：命中条数、已核对/定位数量、匹配层级、最多三个对应条目。
5. 单书分览统一使用现有 `literature-*` 卡片样式展示全文信息。
6. 六爻 matcher 增加 `levelKey` 与 `excerptType`，对齐八字展示模型。
7. 两类排盘重新计算时分别把自己的古籍筛选恢复为“总览”。

## 边界

- 没有改变任何古籍 matcher 的命中条件。
- 没有更改古籍原文、现代提示或适用边界。
- 没有修改八字 / 六爻核心计算。
- 旧 `classic-*` CSS 暂不删除；`classic-source` 仍被《周易》经文区使用，其余遗留样式后续可在独立 CSS 清理中处理。
