# 龟甲 v13.44.0-alpha.4 · 时间效力模型重构第 4 步

本阶段新增 Evidence Selector 证据层，在 Node Assessment 之后并行绑定可追溯证据，但不切换正式用户输出。

## 核心变化

- 新增 `js/liuyao-time-evidence.js`。
- 摘要每个六维效力必须有证据覆盖，`uncoveredKinds` 必须为空。
- compound Fact 结构化吸收子事实；同实体同语义证据去重，不跨爻误合并。
- “出空 + 逢值”可在 Evidence 层组合成内部复合证据并保留来源事件。
- 固定三条不再是证据覆盖硬上限；复杂节点可自动扩容，简单节点不为凑数添加冗余事实。
- 补足旬空填实 / 冲空的纯 Fact 语义组件。

## 压力测试

- 4096 卦 × 12 日支 = 49,152 次 Evidence 选择。
- 无效 0、未覆盖维度 0、异常 0。
- 平均 1.74 条证据，最大 4 条，仅 10 个节点需要超过三条。
- 分散原子事实合成内部复合证据 512 次；compound 子证据吸收 3,392 次；同实体同语义去重 41 次。
- 与 alpha.3 比较，4096 组用户可见范围分析 0 差异。

## 本阶段不做

- 不替换旧 `effectSummary`。
- 不替换旧 `selectRangeDisplayEvents()` 正式展示。
- 不替换日期排序与关键节点筛选。
- 不处理 1100 天长范围上限。
