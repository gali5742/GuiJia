# 龟甲 v13.44.0-alpha.11 · Candidate Output 用户文案收束

## 目标

在不修改六维时间效力、结构相关性与已冻结 Date Selection comparator 的前提下，把新模型的 Candidate Output 收束为可直接进入 beta 前台的用户文案。

本阶段仍不切换正式页面与「复制分析上下文」。

## 文案规则

1. **节点摘要只翻译既有六维 Assessment。** 单一实质维度配合触发时，统一写作“触发中见生扶 / 比和”或“触发伴随受制 / 泄力 / 耗力”；多维效力继续使用“并见”，不重新引入正负总分。
2. **泄力 / 耗力主体明确。** 观察爻生目标日统一显示“观察爻泄力”；观察爻克目标日统一显示“观察爻耗力”。
3. **证据角色化。** 观察爻的出空、填实、冲空、月破复核使用“观察爻……”标签；复合“出空并逢值”继续按观察爻 / 生扶爻 / 克制爻 / 比和爻角色显示。
4. **避免同义括注。** 不显示“目标日生扶（生扶）”“观察爻泄力（泄力）”一类重复说明；只有证据标签没有直接表达的实质维度才补括注，例如“静爻逢冲·日破（受制）”。
5. **证据先看观察对象。** Candidate 可见证据优先排列主要观察爻相关事实，再按实质维度覆盖、层级与原始顺序稳定排序；Evidence Selector 的最小覆盖集合本身不删减。
6. **日期选择文案不改比较逻辑。** 并列仍明确说明“各有侧重”；第二非支配前沿若有多个日期，“次看”全部列出，不任意截取其中一个。
