# 龟甲 v13.42.13 发布说明

v13.42.13 为正式上线前的首页收尾版本，不修改八字或六爻排盘、取用、结构解读与应期算法。

## 本次修改

- 首页底部新增统一免责声明，八字与六爻输入首页共用：龟甲仅供传统文化学习、研究与娱乐参考。
- 明确排盘与分析内容不构成医疗、法律、投资等专业意见，也不作为现实决策的唯一依据；重要事项应结合实际情况并参考相应专业意见。
- 免责声明采用低强调度页脚样式，宽屏与主输入区对齐，窄屏自动恢复全宽，不干扰排盘主流程。
- 自有 CSS / JS 缓存参数、README、部署清单与 package 版本同步到 v13.42.13。

## 验证

发布前执行：

```bash
npm run predeploy
```

并继续执行 Pages 构建与 vendor 校验。
