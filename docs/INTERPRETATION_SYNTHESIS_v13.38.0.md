# v13.38.0 结构解读交叉合成与古籍条件核对

本轮同步优化八字与六爻解释层，不改变排盘规则或 CSS。

## 八字

- 同一组天干关系重复作用时合成为一个命题。例如年、月两丙同时冲时干壬，不再只取第一条关系。
- 对重复地支关系生成具体网络命题。例如双午自刑且两午分别破卯，会合成为“共同作用点”判断。
- 《子平真诠》正官条增加可机器核对条件：财星、印星以及当前宽口径原局是否见刑冲破害。
- 《穷通宝鉴》已核对月令条目增加原文点名天干出现情况核对；同五行异干不会自动替代原文指定天干。

## 六爻

- 用神状态标题直接描述实际状态，不再使用“得扶亦受制”等泛化标题。
- 元神、忌神、仇神的解读同时带入各爻日月、空破、动静状态。
- 当用神/元忌与世应身份落在同一爻对上时，合成为一个“角色重合”命题，避免重复输出独立世应判断。
- 非用神动爻若原爻或变爻进入元神/忌神/仇神五行链，会纳入结构解读。
- 同一实际日期被多个应期规则命中时合并为一个候选，保留多条触发依据。
- 未填写占问时，复制上下文明确提示人工选定用神无法被程序核验。
- 暗动古籍条目对当前程序可确认的“静爻、日冲、月令有气/扶持”逐项核对。
