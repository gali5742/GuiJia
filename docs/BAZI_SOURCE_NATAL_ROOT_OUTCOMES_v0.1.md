# R37 · 寅申冲中的根效力

本轮核对《滴天髓阐微·干支总论》的三造。四甲造提供日主根的明确断语，另外两造出自“地生天者，天衰怕冲”同一段的前后例。依据只取原局四柱及对应评语，排在时柱后的运柱和行运中的另一次冲均排除。[《滴天髓阐微》](https://zh.wikisource.org/zh-hant/滴天髓闡微) · [前后造原文](https://daizhige.org/易藏/术数/滴天髓阐微.html)

| 原局 | 从原文可定位的作用 | 还可从记录中核对什么 |
| --- | --- | --- |
| 甲申、甲戌、甲寅、甲戌 | 年申冲日寅，作者明确说日主的禄根已拔 | 日寅所藏甲在四柱中仍有位置，按 R35 属重根类别。原文在这一造判其失效。日主根记录和古例结论通过同一个藏干标识关联。 |
| 甲寅、戊辰、丙寅、丙申 | 时申与两寅有冲，作者评价原局冲力不足，并指出时干比肩盖头 | 保留涉及的两组位置。在原文未分别说明年寅和日寅各自根效力的情况下，两处都保留待定。 |
| 壬申、甲辰、丙寅、丙申 | 年申、时申共同冲日寅，作者明确点名甲木根拔 | 日寅同时藏甲、丙、戊；断语仅对应木根。可定位受作用的根，归属于哪一明干仍待定。两组冲共享一个来源结果。 |

其中第三造已在此前的明干化杀研究中作为边界案例出现。此前留存的问题是壬水生印能否唯一绑定具体受生者。本轮的证据回答冲到哪一处木根，仍保留那条生印关系的旧结论。[此前的来源审查](BAZI_SOURCE_VISIBLE_MEDIATION_CALIBRATION_v0.1.md)

## 在排盘研究结果中核对

`strengthSynthesis.sourceNatalRootInteraction` 按精确四柱匹配。输出包括原文章节、短引、各冲所涉的具体柱位和结构记录。已确认的根拔在 `rootOutcome` 中记录为 `ineffective`，适用范围是该造该根。两造对读不能给出按申、寅个数判胜负的规则。

运行时重新核对申、寅双方身份、实际六冲结构和藏干清单。日主根还须对应当前的根状态及六冲记录。任一必要位置缺失、重复或与已有根状态相反时，研究输出列明缺口。原文的冲力判断与单根效力分字段保存。通用根效力评估和全局身强弱仍需独立依据。
