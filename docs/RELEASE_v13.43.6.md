# 龟甲 v13.43.6 · 六爻 KeyLine 状态收束

## 目的

收紧 v13.43.5 的关键静爻判定，落实“状态 ≠ 重要性”：旬空、月破、入墓等只描述爻的状态，不能反过来让一个与当前问题无直接关系的普通静爻升级为关键节点。

## 变更

- 静爻先判定是否属于 KeyLine，再进入旬空 / 月破状态机。
- KeyLine 依据角色与结构确定：
  - 世爻 / 应爻；
  - 当前明确取用类别中的同类候选；
  - 与主要观察爻存在生扶、克制、间接制约或比和关系的爻；
  - 当前三合结构成员。
- 旬空 / 月破本身不再构成 `isKey` 条件。
- 前台将“关键静爻”改为角色化提示：如“应爻”“生扶爻”“克制爻”“同类候选爻”“三合成员”。
- 既有动爻、变爻、三合、目标日与主要观察爻规则保持不变。

## 固定回归

以 2026/8/10 丙辰日起卦的节静卦手动向量为基准：

- 世爻巳火；上爻子水为克制五行且旬空：8/18 子日应保留“克制爻出空并逢值”。
- 三爻丑土仅有旬空状态、无世应 / 取用候选 / 直接角色 / 三合结构成员身份：不得因 8/19 丑日出空后逢值而单独形成关键节点。
- v13.43.5 的无妄静卦回归继续通过：应爻出空并逢值、生扶爻月破逢值复核仍保留。
