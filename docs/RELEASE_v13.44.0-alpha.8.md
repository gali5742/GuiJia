# 龟甲 v13.44.0-alpha.8 · Structural Relevance 第 8 步

## 目标

在六维效力与非补偿 Date Selection 之外，增加独立“结构相关性 / 触发重要度”层，只用于细化实质效力组合完全相同的日期，减少无原则并列，同时避免重新引入隐藏总分。

## 结构相关性层级

从高到低：

1. 直接作用于观察爻（observer-direct）
2. 观察爻之变（observer-change）
3. 世应轴（axis）
4. 关键关系爻（key-line）
5. 结构组合（formation）
6. 背景结构（context）

该层只描述一个 Effect 的来源离主要观察对象有多近，不改变 Effect 的类别。

## 日期选择边界

- Structural Relevance 仅在 material signature 完全相同的日期之间参与比较。
- 有利维度（生扶 / 比和）若均已存在，则来源更直接者可优先。
- 负担维度（受制 / 泄力 / 耗力）若均已存在，则来源更直接代表负担更直接，因此较不利。
- 触发重要度只在“纯助力”或“仅负担”的同质场景中细化：纯助力更直接的触发优先；仅负担则较不直接的触发优先。
- 混合场景不单独依赖 trigger rank 排序。
- 不规定生扶 > 比和，也不规定泄力 > 耗力。
- alpha.8 第一前沿必须是 alpha.7 第一前沿的子集，不允许跨不同实质效力组合移除日期。

## 压力结果

4096 卦“这周哪天适合出行”：

- alpha.7 单一第一候选：760（18.55%）
- alpha.8 单一第一候选：1641（40.06%）
- alpha.7 并列：3336（81.45%）
- alpha.8 并列：2455（59.94%）
- 第一前沿实际被细化：2979 卦
- 被移出第一前沿日期：4441
- 第一前沿子集违规：0
- 跨实质效力组合误移除：0
- 最大第一前沿：5 → 4

本固定语料中，4441 个移除全部由触发重要度完成；实质维度来源相关性本身没有产生额外移除。剩余并列中 2035 卦仍包含“纯生扶 vs 纯比和”，说明结构相关性不能也不应代替术数原则来强行决定二者高低。

4096 卦“明天还是周五哪个好”保持 4096 / 4096 单一第一候选，alpha.8 未改变前沿。

## 用户接口

无变化。正式页面与「复制分析上下文」继续使用 legacy 时间输出；Structural Relevance 仍为内部并行验证层。
