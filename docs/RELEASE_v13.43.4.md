# 龟甲 v13.43.4 · 六爻关键动爻逢值补全

## 范围

本版本继续收尾六爻“自然语言占问时间 / 时间范围分析”专项。只修复范围事件池的漏检，不扩时间词库，不修改八字、六爻纳甲、八宫、世应、六神与 vendor 依赖。

## 主要变化

1. 普通非空关键动爻逢值进入一级范围候选：覆盖生扶、克制、间接制约和五行比和四类与主要观察爻有明确关系的本卦动爻。
2. 世 / 应身份不再阻止关键动爻逢值提升；若应爻发动且属于上述明确关系，逢值同样作为关键节点。
3. 已经由主要观察爻、关键动爻、旬空状态等规则选中的日期，会继续补充其他动爻变爻的逢值、逢冲、逢合。
4. 变爻原有化月破时，逢值显示“变爻逢值·月破复核”；化空继续交由既有冲空 / 出空 / 填实状态转换处理。
5. 普通变爻关系仅作为 context 级补充事实，不会单独把一个低区分度日期抬成过程关键节点。

## 手动测试回归

固定“丰之大有、世爻申金、二爻丑土旬空发动、上爻戌土发动”的 2026/8/15～20 出差时间范围：

- 8/16 戌日：上爻戌土为世爻申金的生扶五行动爻，必须出现“生扶动爻逢值”。
- 8/18 子日：二爻丑土原旬空出空。
- 8/19 丑日：二爻丑土出空后逢值。
- 8/20 寅日：世爻申金逢冲节点中，同时补充二爻化寅木“变爻逢值·月破复核”。
