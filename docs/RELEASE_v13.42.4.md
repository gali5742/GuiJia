# 龟甲 v13.42.4 发布说明

v13.42.4 在 v13.42.3 的普通语言“观察重点”基础上补入感情、恋爱与婚姻大类，并用传统婚占文献约束财官取用，不修改八字或六爻核心排盘算法。

## 感情、恋爱与婚姻

- 新增“感情、恋爱与婚姻”观察重点；普通关系问题以应爻作为关系对象的观察起点，同时保留世应与财官结构。
- 高置信占问规则增加恋爱、感情、婚姻、结婚、复合、分手、表白、相亲、暧昧、伴侣等明确关系词。
- 明确“丈夫／老公”时按传统婚占取官鬼，明确“妻子／老婆／媳妇”时取妻财。
- 男朋友、女朋友、男友、女友等现代恋爱对象只识别为感情关系大类，不依据对象性别自动套用财官，避免推断占问者身份或把现代关系硬套进传统夫妻角色。
- 若财务、工作等事件焦点更明确，则仍由对应高置信规则优先；多个方向接近时保持“暂未自动判断”。

## 文献依据

- 《黄金策·婚姻》同时以世应关系、财官状态论婚姻，并有“夫若才能，官位占长生之地；妻如丑拙，财爻落墓库之乡”等明确夫官、妻财用法。
- 该章末注又明确其所论为男卜女婚、女卜男姻，并提醒不可在其他亲属关系中概以财官代替实际用神。程序据此只在明确夫妻角色时自动套用财官；其余感情关系先从世应关系切入。

## 验证

- 感情类高置信问句、夫妻角色问句、现代恋爱对象问句与财务焦点覆盖测试。
- 八类观察重点的 4096 卦映射压力测试。
- 既有模糊问句反例、主回归、Lunar 集成与 `predeploy` 检查。
