## Normalization and generic target resolution

Each input consists of an exact registered annotation and its exact registered path-source snapshot. Validation preserves target/antecedent/source-role spans, source tier, condition/link/assertion/path IDs, shared source context and compound intermediate roles. Edits, omitted antecedents, substituted source excerpts, injected actor/group bindings or authority fields fail closed before invoking the existing adapter.

`normalizePath` calls the existing `normalizeCase` adapter with the validated annotation and no actor-group/hidden bindings. It retains target span, mention mode, antecedent and role without inserting an expected level, semantic-level hint or legacy resolver decision. `resolvePath` calls the existing generic `resolveRecord` kernel, whose GTLR-R03 rule resolves the resulting theory/generalized-rule unit to a role-class target. There is no new target-decision kernel.

The normalized source unit has `bindingRequired:false` and `identity-not-required` because interpreting that theoretical role requires no chart identity. This does **not** waive identity requirements for runtime instances. The separate review keeps `instanceIdentityAuthorized:false`, no actor keys/scope/cardinality and an explicit missing-instance-identity blocker. Role interpretation succeeds while runtime target identity remains unresolved; this differs from both invalid source provenance and no-relation-target.

The 财转食党煞 compound path is one target unit with a retained compound predicate and 食神 intermediate provenance. It is not decomposed into direct/member edges and gains no effect-type hint or authorization.

## Runtime integration and remaining work

Research bootstrap v0.35 loads the three R13 modules explicitly. Full synthesis exposes `contextualForcePartySourcePathTargetAnnotation`. Before joining source target reviews to actual partial paths, it recomputes and exactly compares the current-chart R12 participant profile. Missing, edited or cross-chart profiles, including forged target endpoints, reject the runtime join. Static source annotations cannot repair a tampered R11 batch or instantiate unmatched/proximity paths.

Valid partial runtime paths retain their existing source/intermediate identities, original target endpoint and chart-scoped instance ID. A separate target semantic review is attached; the target identity review remains unresolved. R12 data is not mutated. All outputs and copied provenance are deeply immutable.

The dedicated narrow source-coverage dependency covers six annotated target units in three records and their existing-kernel resolution, with validated runtime consumption. It does not claim the entire Competing Relation Path registry or broader relation-source annotation corpus. CF-CRP-REC-04's two relative-capacity paths remain outside this stage. Target identity authority count and complete runtime target count both remain zero. B02–B05, broader annotation coverage, generic position/competing-path resolution and final Strength/Assessment remain unresolved. Existing R9 mediation, production runtime and LiuYao behavior are preserved.

The full-bootstrap regression uses synthetic condition fixtures, not newly sourced classical chart cases or positive effect calibration. It covers exact target mentions/antecedents, actual normalization/generic-kernel consumption, distinct source tiers, conditional theory context, compound provenance, injected authority refusals, current-chart runtime joins, immutability, dependency integrity and existing calibration boundaries.

Next priority is evidence acquisition and source-scoped instance annotation, rather than another inferred target selector. A selected complete source case or explicitly scoped source pattern must independently identify the target referent, visible/hidden/collective scope and cardinality, and justify its link to the chosen relation path. If no such evidence supports the current order/proximity paths, retain their role-only targets. A separate supported instance calibration must retain its own authority and cannot be generalized back to these paths merely because it shares 七杀/正官 roles. After that, realization, effect-type authorization and path-combination/selection still need their own evidence.
