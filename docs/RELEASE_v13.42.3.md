# 龟甲 v13.42.3 发布说明

v13.42.3 在 v13.42.2 的高置信占问建议之上增加普通语言“观察重点”层，不扩大自动关键词词典，不修改八字或六爻核心排盘算法。

## 普通语言观察重点

- 六爻总览主标题由“用神选择”改为“观察重点”。
- 普通用户先选择想观察的人或事，再映射到既有世应／六亲：自身状态、对方／外部对象、父母长辈学业文书、子女生育宠物娱乐、钱财收入交易、工作职位诉讼疾病、同辈朋友竞争。
- 自动占问建议仍只在高置信度时给出；模糊问句不会因为新增观察重点而扩大关键词命中。
- 同类六亲多现时保留全部候选，并提示当前展开的具体爻；详细分析继续保留完整同类分布。
- 目标类别在本卦明爻和已列伏神中都没有候选时，只提示无候选，不伪造用神。
- 原有专业具体爻选择器下沉到“手动选择具体爻（熟悉六爻时）”折叠项。
- 复制分析上下文记录当前观察对象的选择来源。

## 验证

- 观察重点七类目标映射、世应映射、多现候选、伏神回落与无候选专项测试。
- 模糊占问固定反例继续保持未自动判断。
- 完整主回归、Lunar 集成、静态资源与 `predeploy` 检查。
