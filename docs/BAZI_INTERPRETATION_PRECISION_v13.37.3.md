# 龟甲 v13.37.3 · 八字结构解读命题精度审核

## 目标

把结构解读从“规则类别名称”进一步推进到“当前命盘实际结构”，同时统一通根术语，并减少程序排序式语言。

## 变更

### 1. 天干重复透出

旧逻辑在多个不同十神同时出现时，优先使用类别级标题，如“财星与食伤同见天干”。

新逻辑先统计各十神实际透出次数；若某一十神重复出现并伴随其他十神，则生成：

- `伤官两透，并见正财`
- `正官两透，并见偏印`

等具体标题。若三个非日主天干全为同一十神，仍沿用“伤官集中透出”一类表述。

### 2. 本干通根 / 同类得地

- `exactRoots` → 本干通根
- `sameElementRoots` → 同类得地

这一术语同时用于月令命题、扶身命题和强弱相关证据。

### 3. 地支关系网络

关系摘要会将相同支对上的多类关系合并识别，例如 `申寅` 同时存在冲与刑时，写作“申寅之间同时见刑、冲”。

同时统计地支参与的关系组；同一地支参与三组以上关系时，指出其为多组关系的共同节点。

## 回归样例

`丙午 丙申 乙卯 戊寅`：

- 透干：`伤官两透，并见正财`
- 通根：`卯中乙` 为本干通根；`寅中甲` 为同类得地
- 地支：申寅冲刑并见；寅同时参与申寅、寅午、寅卯三组关系
