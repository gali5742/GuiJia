# v13.39.1 八字详细分析页精炼审计

## 目标

本轮只调整八字“详细分析”页，不修改原局总览、六爻页面、八字排盘算法或 CSS。

详细页继续承担“总览判断为什么成立、还有哪些细节”的职责，并进一步避免两类问题：

1. 只有数据，没有局部归纳；
2. 把空关系、实现说明和开发口吻直接呈现给用户。

## 本轮修改

### 1. 主要模块增加局部归纳

- 日主强弱：先概括季节状态、通根、扶助与泄耗克的方向，再展开落点。
- 十神透藏：先概括哪些十神明透、哪些主要藏于地支，再展示五组分布与细分落点。
- 月令主线：先说明月令本气、对应十神以及本气是否透干，再展开藏干与显隐。
- 干支关系：先概括关系类型与共同节点，再展示具体关系。

这些归纳只使用现有结构事实，不新增吉凶、格局、用神或领域断语。

### 2. 零项关系不再显示

详细页不再显示：

- “未检测到天干五合或天干冲”
- “未检测到直接地支关系”
- “未形成完整三合、三会或完整三刑”
- “未检测到半合或同方未成局组合”

规则改为：**有什么关系，就解释什么关系。**

同时，地支直接关系与完整/未成方局分开呈现，避免同一半合或同方组合在“地支关系”和“未成组合”两处重复。

如果原局完全没有已识别的干支关系，整个“干支关系网络”模块不显示。

### 3. 用户可见语言清理

删除详细页底部高权重的“详细分析使用边界”卡；必要的方法边界已经收束到各模块的一两句自然说明中。

古籍条件对照在详细页展示时，对已有 `contextMatch` 做用户向改写，例如：

- “本程序只确认” → “这里只确认”
- “可机器核对” → “可直接核对”
- “程序已识别结构” → “本局已列结构”
- “当前宽口径原局检查” → “就本局已列关系而言”
- “未编码” → “尚未纳入”

原 matcher 数据本身不改，因此原局总览与复制上下文逻辑不受本轮影响。

### 4. 古籍折叠标题增加条件状态

详细页会在条目标题上显示一条简短状态：

- 已有对应条件
- 条件部分对应
- 存在未满足条件
- 相关条目

该状态只用于帮助决定是否展开，不替代正文条件核对，也不自动表示成格或吉凶。
