# 龟甲 v13.44.0-rc.1

## 定位

时间捕捉 / 时间效力专项的发布候选版本。RC.1 不增加新规则，只修 beta.3 前台手测确认的两个阻断实现错误。

## 修复 1：间接制约五行归入耗力

传统角色中的 `ENEMY / 间接制约五行` 与主要观察爻的直接关系是“观察爻克该五行”。TimeFact 现记录为 `observer-controls-line`；当该爻在目标日逢值、出空、填实、月破复核等被落实时，TimeEffect 归入 `exertion / 耗力`。

普通六冲、六合只保持原有触发语义；未发生落实类事件时，不因为角色标签额外制造耗力。

## 修复 2：主要观察爻直接证据优先

Evidence Selector 在某个摘要维度能够由主要观察爻自身直接证明时，先保留 `main-observer` 证据，再用外围关系爻补齐尚未覆盖的维度。这样同一天出现“观察爻自己逢值”和“外围同类爻逢值”时，正式页面 / 复制上下文不会只留下外围事实。

旧版“已入选日期补充外围变爻状态”的原始 TimeFact 仍保留；当其只重复摘要已经由主要观察爻完整证明的维度时，不再强制挤入正式 Evidence。

## 冻结项

本版未修改：

- QuestionTimeScope 自然语言时间解析；
- KeyLine 判定；
- TimeEffect 六维定义；
- Date Selection 六维非补偿 Pareto comparator；
- Structural Relevance 层级；
- process-range 准入原则。
