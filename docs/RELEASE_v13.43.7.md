# 龟甲 v13.43.7 · 六爻目标日效力合流

## 目的

收束范围时间分析中的“同日多事实”问题：目标日的值、合、冲与五行生克应同时成立，节点效力不能只被高层结构事件单独决定。

## 变更

- 目标日地支关系与五行生克拆为两条并行计算链：
  - 值 / 六冲 / 六合负责结构触发；
  - 生扶 / 克制 / 比和 / 泄耗 / 主动制约负责五行效力。
- 节点效力聚合改为同时读取：
  - 所有 `primary` 关键结构事件；
  - 所有直接作用于主要观察爻的事件，不论其原始 tier。
- 当同一日既有生扶又有受制时，节点汇总明确输出“生扶与受制并见”；观察爻主动克制目标日但伴随耗力时，不再被简单归为“触发偏向生扶”。
- 展示层若节点由相反方向共同构成，会保留至少一条生扶依据和一条受制依据，避免摘要与事实列表相互矛盾。
- 直接月冲（月破）优先于同五行比扶；辰戌、丑未不再因为同属土而误判为得月支持。
- 范围事件新增用户可见语义去重：相同 label + text 的三合事实只显示一次，不再挤占前三条关键事实名额。

## 固定回归

- 子水世爻遇丑日：同时识别子丑六合与丑土克子水，节点为“生扶与受制并见”。
- 辰土世爻遇酉日：同时识别辰酉六合与辰土生酉金的泄耗，节点为“生扶与受制并见”。
- 丑土静爻处未月、再逢未日冲：直接月冲优先，显示“静爻逢冲·日破”，不得显示暗动。
- 重复的“申子辰三合水局 · 待实出空”后台来源只显示一次，同时保留世爻受冲与目标日克制等不同事实。

## 暂不处理

- 长范围分析的 1100 天上限（例如未来四年）。
- 倒序日期、已过期范围、同一日期被不同自然语言重复指定等异常输入校验。
