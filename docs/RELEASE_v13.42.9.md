# 龟甲 v13.42.9 发布说明

v13.42.9 修复六爻“外部对象”自动取用后的观察重点高亮错位。

## 修复

- “合作伙伴、合作方、合伙人、客户、甲方、乙方”等高置信命中仍然取应爻。
- 自动建议现在同时携带 `focusId: counterparty`，观察重点会高亮“对方／外部对象”。
- “感情、恋爱与婚姻”仍使用 `focusId: relationship`。两类虽然都以应爻为观察起点，但 UI 状态相互独立。
- 新增回归测试，防止以后因按 target 回退而再次把外部对象高亮到感情类。

## 未修改

- 六爻排盘与八宫纳甲。
- 世应、日月、旬空、动变、飞伏、三合与应期。
- 自动取用的类别判断本身。

## 发布验证

执行：

```bash
npm test
npm run predeploy
```

并人工确认“合作伙伴是不是真心靠谱”显示：

- 取用类别：应（高置信）
- 高亮：对方／外部对象
- 不高亮：感情、恋爱与婚姻
