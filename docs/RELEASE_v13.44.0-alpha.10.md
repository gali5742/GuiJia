# 龟甲 v13.44.0-alpha.10 · 六维 Date Selection 重构与冻结

## 目标

把 alpha.9 已经独立审计过的六维非补偿 Pareto 正式接入 Candidate Date Selection，结束日期选择判断原则的探索阶段。

本阶段仍不切换正式页面与「复制分析上下文」。

## 冻结后的日期比较原则

1. **受制为硬门槛。** 只要范围内存在未受制日期，第一前沿先在未受制层产生；若所有候选均受制，再在受制层内部比较。
2. **生扶、比和独立。** 两者都是有利维度，但不互换数值；“生扶+比和”可以支配“只有生扶”，纯生扶与纯比和则不可自动决胜。
3. **泄力、耗力独立。** 两者都是软负担，但不规定固定轻重；“只有泄力”可以支配“泄力+耗力”，纯泄力与纯耗力则保留不可比。
4. **非补偿 Pareto。** A 只有在所有实质维度都不差、至少一项严格更好时，才支配 B。多一个助力同时多一个负担属于真实权衡。
5. **Structural Relevance 只细化同质日期。** 实质效力组合完全相同后，才比较作用来源的直接程度；不得跨六维边界重新排序。
6. **不使用隐藏总分。** 不以“减少并列”为目标。

## 4096 卦一周选日验收

固定问题：`这周哪天适合出行`。

- 有效卦数：4096
- schema / 运行异常：0
- 生产六维 comparator 单一第一候选：1368（33.40%）
- 生产六维 comparator 并列：2728（66.60%）
- 最大第一前沿：4 天
- 与独立六维 Pareto 第一前沿完全一致：4096 / 4096
- 生产前沿严格多删/少删：0
- 未分类剩余并列：0

剩余并列主要是纯生扶 vs 纯比和、完全同质日期、纯泄力 vs 纯耗力，以及额外助力与额外软负担之间的真实权衡。这些不再视为待修 bug。

## 两日比较验收

固定问题：`明天还是周五哪个好`。

- 有效卦数：4096
- 单一第一前沿：4096 / 4096
- 并列：0
- 受制硬门槛违规：0
- 第一前沿仍被同层其他日期支配：0

## 停止条件

alpha.10 起冻结日期选择术数原则。后续阶段只允许修复违反以下条件的实现错误：

- 受制日跨硬门槛进入第一前沿；
- 第一前沿存在同层可被六维 Pareto 支配的日期；
- Structural Relevance 跨实质效力边界排序；
- 使用隐藏权重或总分改变结果；
- 页面摘要与证据不一致。

纯粹因为并列率高、文案还能更漂亮、存在未定义的术数偏好，不再回头修改 comparator。

## 用户接口

无变化。正式页面、复制分析上下文、时间解析、KeyLine 和关键节点筛选仍保持 legacy 路径。
