# 龟甲 v13.43.3 · 六爻关键爻时间状态与明确候选收束

## 范围

本版本继续收尾“自然语言占问时间”专项，不扩时间词库，不修改八字、六爻纳甲、八宫、世应、六神与 vendor 依赖。

## 主要变化

1. 关键动爻的旬空状态转换独立进入范围事件池：支持冲空、出空、出空后逢值；化空变爻同样适用。
2. 已成 / 待实三合中的动爻成员逢值提升为一级结构触发，避免过程型范围只盯主要观察爻而漏掉卦中关键动爻。
3. 目标日期进入新旬时会复核该支在目标旬是否仍为空，避免把“原旬结束”机械等同于已经出空。
4. 明确单日、离散候选与连续有界范围启用目标时间分析后，普通“应期观察”不再重复显示；模糊时间和开放式未来搜索仍保留应期。
5. 日期比较事项未明确时，页面与复制上下文明确写明“仅按世爻状态作为当前比较基准”，比较结论改为相对观察顺序。
6. 过程型范围继续使用阈值筛选，事件池补完整后再决定展示，不恢复固定数量 fallback。

## 回归重点

- `8月15日至20日出差如何`：旬空动爻出空 / 出空后逢值与三合成员逢值可以进入关键节点。
- `明天还是周五哪个好`：只显示“目标时点”，不再重复“应期观察”；事项不明时出现世爻比较基准提示。
- `这周哪天适合签合同`：已有明确父母取用时保持原日期比较逻辑，不因本次降级规则而弱化。
