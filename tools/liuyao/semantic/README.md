# Semantic development pages

本目录只保存六爻 Semantic 开发/验证页面源码。

- `router/`：Router / candidate / decision / runtime。
- `decision-stack/`：Decision Stack 开发与 sealed blind 页面。
- `resolution/`：Object / Entity / Contextual Role 解析页面。
- `gates/`：Scope / Sufficiency / Slot Provider 门控页面。

GitHub Pages 构建仍保持旧的站点根 URL，以兼容历史测试链接；源码位置与部署位置不再一一相同。
