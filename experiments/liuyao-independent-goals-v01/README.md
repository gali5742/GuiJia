# 占问中的独立结果

手工标注 48 条训练题与 42 条全新评估题，保留原文、起止位置、背景、排除、请求、重述以及各请求对应的结果编号。同一结果的重述共用一个编号。不同人、事或时间的独立结果分别编号。训练与评估各一半单问、一半多问。输入题目和人工答案分别使用；评估含六条连续无标点文本。近重复检查覆盖本实验新题、历史训练与历轮允许的诊断集。保留集不读取。

在冻结的中文 BGE 表示上拟合两个分类器，一个识别片段的背景、排除或请求提及，另一个依据两个片段的向量绝对差和余弦相似度识别两次提及是否指同一结果。相互判定同一结果的片段归组。待判文本以常见标点和空白生成片段，不接收人工边界或目标个数。出现至少两个片段、至少一个目标且用到的判断置信均达 0.55 时，按独立组数判断是否停止。其他输入沿用已保留的全句计数器。多问停止后主题定位与业务路由均零调用。用于计数的片段识别发生于入口。实际业务路由、主题定位器、旧基线权重和阈值保持固定。

评分前固定 42 条新题和两套回归题（关联占问 48 条，主题扩展 70 条）。除漏放、误停、业务误选及业务分类正确数外，记录逐字目标范围及分组是否匹配、背景与排除角色是否匹配、候选实际采用结构化判断的频次。只有新题多问漏放下降、单问误停不升，且两套回归各自的漏放、误停和已知单问正确路由都不恶化，才保留作下一轮研究基线。另报告已漏过并实际选定主题的多问。未达标则保留 31 类研究基线。本实验未在真实提问流量上验证。
