# 从原版十个观察重点扩展六爻占问主题

本轮的依据为 `js/liuyao-core.js` 中的 `USE_GOD_FOCUS_OPTIONS`。十项是解卦时的观察方向。一句占问可以涉及几个方向，例如「儿子考完试会回我电话吗」涉及子女、考试、外部回应，但只要求判断一个结果。表中每行列出已覆盖的目标、第一批新增目标，以及仍需定义的边界。人物关系允许跨行使用，不自动触发某条取用规则。

| 原版观察重点 | 上轮已登记的现实目标或交叉关系 | 第一批新增 | 后续边界 |
|---|---|---|---|
| 自己当前的状态 | 本人可为求职者、考生、旅客等 | 保留本人为参与者 | 区分特定事项中的自身状态、事务能否完成、缺少判断目标；健康类沿用产品边界 |
| 出行、旅行与行程 | 特定行程能否成行 | 特定交通班次是否停开或延误 | 行程受阻、旅人何时归来等分别定义 |
| 感情、恋爱与婚姻 | 感情发展、婚配、既有婚姻 | 亲属回信与夫妻关系做对照 | 分清联系行为、关系走向与婚姻结果 |
| 对方／外部对象 | 对手方可出现于签约、付款、合伙等 | 已发出联系后，特定亲人是否回复 | 泛指客户回复、争议中对方是否撤诉等另行审查，不能一律套用亲属规则 |
| 父母、长辈、学业与文书 | 资格考试能否通过；收到文件可能属于收物 | 本人或子女的考试排名；长辈可为回复者 | 考试分数、学业进度、录取、文书办结与收到文书分别处理 |
| 子女、生育、宠物与娱乐 | 子女可为考生，可代问其资格考试 | 孩子考试排名、孩子回复联系作为具体目标 | 宠物行为、娱乐体验需另立目标；生育相关须先核对健康边界 |
| 失物与寻找 | 特定遗失物品能否找回 | 以寻物为背景的单问用于区分交通问题 | 失物位置、寻人、宠物走失分别处理 |
| 钱财、收入与交易 | 整体财务、工资、奖金、经营、交易、进货、售货、借入、借出、收债、偿债、合伙，及投资收益、退出、适宜性、持仓调整、价格走势；另有收物与购置物品 | 收债与官司胜负、工资与晋升、收件与回话做对照 | 同一交易中的付款、履约和交付可能是不同目标 |
| 工作、职位与诉讼 | 具体岗位应聘结果 | 在职晋升；特定官司或仲裁的裁判结果 | 留任、转正、程序受理、是否和解分别定义 |
| 同辈、朋友与竞争 | 同辈可出现于合伙、借贷等 | 手足回复联系；测试中单列竞技名次与考试排名的区别 | 朋友与手足区分；一般竞赛胜负和同辈关系仍需新规则 |

第一批五个职责分别对齐 `liuyao-travel-pretraining-v01.js`、`liuyao-person-contact-pretraining-v01.js`、`liuyao-study-exam-pretraining-v01.js`、`liuyao-career-position-pretraining-v01.js` 和 `liuyao-litigation-dispute-pretraining-v01.js` 的已有研究设计。该实验只识别语义目标。原版观察方向、参与者关系以及传统取用规则均不作为推理输入。

## 冻结的训练与验证设计

沿用上轮多问判断和 26 类路由权重，先判断整段占问有几个问题，判为多问时直接返回。上轮的诉讼留题只用于去重，旧评估结果仍按旧范围解释。五个新职责每类 8 条手撰训练单问，并补 12 条容易混淆的其他目标。每条标有原文目标片段。新增分类器训练时使用全句及不同于全句的目标片段，二者均使用同一业务标签；旧 22 类各取训练集前两题，另取此前训练集的四种扩展类别各两题，作为回退类对照。所有推理阈值在测试前固定。

候选片段按常见中文标点分割，用训练文本的片段和背景监督训练一个独立二分类器，挑出最可能表达问题的片段。比较同一新增分类器读整句、自动选择片段与人工给定片段三种方式。未达到新增分类阈值 0.5 时沿用原始全句的 26 类分类器。人工片段只作误差诊断，不进入模拟入口。冻结计数器以 0.5 判断多问。本轮不训练人物角色提取器。

70 条手撰新题包含五个新增目标各 6 条、旧 26 类各一条、范围外 6 条和多问 8 条。新增目标各有一条无标点并含背景的输入。独立报告单问主题识别、完整入口、旧类退化、范围外误选、多问误放、目标片段命中。相同旧类每类仅一条。训练题与评估题及历轮授权对照集做规范化完全重复和三字片段 Jaccard 0.82 检查。保留集不参与。指标用于比较研究方案，不能估算实际提问分布。
